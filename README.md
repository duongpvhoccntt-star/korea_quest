# 🇰🇷 KOREAQUEST

An engaging Flutter mobile application designed to explore Korean culture, language, and quests.

## 🚀 Features

- **Interactive Quests**: Learn Korean culture, language, and history through fun quests.
- **Cross-Platform**: Powered by Flutter for seamless performance on Android, iOS, Web, and Desktop.
- **Modern UI**: Clean and intuitive user interface built with Flutter components.

## 🛠️ Tech Stack

- **Framework**: [Flutter](https://flutter.dev/) (Dart)
- **State Management**: Standard Flutter state management / Provider / Riverpod ready
- **Platforms**: Android, iOS, Web, Windows, macOS, Linux

## 🏁 Getting Started

### Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install) installed (v3.0.0 or higher recommended)
- Dart SDK installed
- Android Studio / VS Code with Flutter extension
- An emulator or physical device for testing

### Installation & Running

1. **Clone the repository:**
   ```bash
   git clone https://github.com/duongpvhoccntt-star/korea_quest.git
   cd korea_quest
   ```

2. **Install dependencies:**
   ```bash
   flutter pub get
   ```

3. **Run the app:**
   ```bash
   flutter run
   ```
