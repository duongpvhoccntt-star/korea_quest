# Dùng Hành trình Địa điểm gồm chín Chặng tuần tự

KoreaQuest thay luồng Check-in → Văn hóa → Từ vựng → Tổng kết bằng Mở đầu → Tổng quan → Lịch sử → Điểm đến → Trải nghiệm → Ẩm thực → Fun Facts → Quiz tổng kết → Du lịch để khớp thiết kế Stitch và nội dung thực tế. Các Chặng mở tuần tự; Quiz yêu cầu đạt tối thiểu 70% để mở Du lịch, còn việc hoàn thành Du lịch kết thúc Hành trình và trao phần thưởng lần đầu.
